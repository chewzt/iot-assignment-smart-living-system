How this panel works

1. Click a manual command → dashboard writes target state to /controls and sets mode to manual.
2. ESP32 reads the request, applies the actuator, then writes the actual result to /status and /devices.
3. The requested/actual chips here let you see whether the device is still pending or already synced.
